# UI 信息架构重构 + 功能占位 Demo — 设计文档

> 日期:2026-06-02 · 状态:已对齐待实施
> 性质:**纯前端 UI demo**。重构导航信息架构,为四大目标(行情分析 / 策略回测 / AI 助手 / 自动交易)预留清晰页面位置。

---

## 0. 范围与基调(最重要,先读)

**本轮交付 = 纯前端 UI 重构 + 占位 demo,零后端改动。**

- **现有真实页面**(概览 `/`、行情 `/market`、自选 `/watchlist`、个股详情 `/symbol/[code]`)**原样保留**,只在新导航里重新归位,不改其数据逻辑。
- **新增/重做页面**(CD 信号 `/signals`、设置 `/settings/*`、策略回测 `/strategy`、AI 助手 `/assistant`、自动交易 `/trading`)**全部用写死的假数据渲染**,不接任何 API、不调后端、不落库。
- 目的:验证**信息架构是否合理、页面层次是否清晰、跳转是否通**。不是把数据拉通。
- **不碰**:任何 `apps/api/`、`apps/collector/`、`core/`、数据库 schema。所有改动限定在 `apps/web/`。

**为什么这么做**:四大目标里只有"行情分析"已实装,策略/AI/自动交易都是后续工程。先用 demo 把"最终产品长什么样、各功能住在哪"定下来,作为后续逐个真做的骨架与导航契约。

---

## 1. 视觉风格基调

延续现有设计语言(已经是简洁专业风,不重做):
- 暗色为主(`data-theme="dark"`,现有 light 切换保留),CSS 变量体系沿用 `--bg/--text/--text2/--text3/--border/--accent/--green/--red`。
- 等宽字体用于数字(价格/代码/时间),无衬线用于文本。
- 卡片/面板用现有 `.panel` `.panel-header` `.data-table` 等 class,不引入新 UI 库。
- 涨跌色:A股口径(红涨绿跌)与现有一致。
- **不花哨**:无渐变滥用、无动画堆砌,占位页的"假数据"也走同一套朴素卡片/表格样式,保证 demo 和真实页面观感一致。

## 2. 信息架构(导航结构 — 方案 A:按使用场景平铺)

## 4. CD 信号页 `/signals` 细节(假数据)

**布局:单列时间流(方案 A)**

```
┌─ 顶部筛选条 ────────────────────────────────────────┐
│ [全部市场] A股 美股 Crypto | [买入] 卖出 | 周期: 1d ▾ │
├─ 事件流(按时间倒序,假数据)────────────────────────┤
│ ▲买入  贵州茅台  600519·1d  底背离        06-02 15:00 │
│ ▼卖出  NVDA     英伟达·4h   顶背离        06-02 03:00 │
│ ▲买入  BTC      比特币·1h   底背离        06-01 22:00 │
│ ▲买入  宁德时代  300750·1d  底背离        06-01 15:00 │
│ … (约 15-20 条写死假事件)                            │
└──────────────────────────────────────────────────┘
```

- **筛选条**:市场 chip(全部/A股/美股/Crypto,单选)+ 买卖 chip(买入/卖出,可都选)+ 周期下拉(1d/4h/1h/30m/15m)。纯前端过滤写死的假数组,无网络。
- **事件行**:买卖 badge(红=买/绿=卖,A股口径)、标的名+代码+周期、信号类型(底背离/顶背离)、时间。整行可点 → `/symbol/[code]`(跳现有真实详情页)。
- **假数据来源**:组件内写死的 `const FAKE_SIGNALS = [...]`,覆盖多市场/多周期/买卖混合,约 15-20 条,时间戳用近几日固定值。
- **空状态**:筛选无结果时显示"当前筛选无信号"。
- **首页 / 详情页的信号呈现**:本轮**不改**现有首页"最近信号"摘要和详情页 CD 标记(它们走真实数据,保留)。`/signals` 是新增的独立浏览页。

## 5. 占位页假数据规格

所有占位页用统一的"假数据 + 朴素样式"基调,与真实页面观感一致。每页顶部加一行浅色提示条:`🧪 功能预览 · 数据为演示用途`。

### 5.1 `/strategy` 策略回测
- **列表**:卡片网格,每张卡 = 假策略(名称/描述/假年化/假最大回撤/状态徽章),约 4-6 张。点卡 → `/strategy/[id]`。
- **`/strategy/[id]` 报告**:假资金曲线(SVG/canvas 画死折线或用现有图表组件喂假 bars)+ 假绩效指标表(总收益/年化/夏普/最大回撤/胜率/交易次数)+ 假交易记录表。

### 5.2 `/assistant` AI 助手
- **聊天式布局**:中间对话流(AI 主动播报气泡 + 用户提问气泡交替,假对话约 4-6 轮)+ 底部输入框(可输入但提交只追加一条"演示模式暂不可用"假回复或静态占位)。
- 主动播报示例:"今日 A 股放量上涨,北向净流入 X 亿,科技板块领涨…"(写死)。

### 5.3 `/trading` 自动交易
- **假持仓表**(标的/数量/成本/现价/盈亏)+ **假订单流**(时间/方向/标的/价格/状态)+ **风控开关区**(几个 toggle,纯展示,如"启用自动交易""单笔上限""最大持仓")。
- 顶部醒目假状态条:"自动交易:已停用(演示)"。

### 5.4 `/settings/notifications`(假)
- **收件人区**:假邮箱列表(地址/启用 toggle/删除按钮)+ 添加输入框。增删改只改本地 state,不落库、不调 API。
- **按标的周期区**:假自选标的列表,每个标的一行 + 周期复选(15m/30m/60m/4h/1d,1d 默认选中禁用)。改动只改本地 state。
- 说明:此页**有意做成假的**——虽然后端 `notification_recipients`/`symbol_notification_config` 表和 `RecipientManager`/`SymbolConfigManager` 真实组件已存在,但本轮基调是纯 demo,**不复用真实组件、不打后端**。后续真做时再接回现成后端(届时删假数据、挂真实组件即可)。

## 6. 实施约束与组件边界

- **改动范围**:仅 `apps/web/`。不碰 api / collector / core / DB。
- **新增文件**:`app/signals/page.tsx`、`app/strategy/page.tsx`、`app/strategy/[id]/page.tsx`、`app/assistant/page.tsx`、`app/trading/page.tsx`、`app/settings/page.tsx`(重定向)、`app/settings/notifications/page.tsx`、`app/settings/preferences/page.tsx`、`app/settings/about/page.tsx`。假数据可各自内联或集中放 `lib/demo_fixtures.ts`(**推荐集中**,便于后续删除)。

- **不复用**:`/settings/notifications` 不导入真实 `RecipientManager`/`SymbolConfigManager`(避免打后端);`/signals` 不调 `cd_signals_api`。
