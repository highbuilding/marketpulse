# 富途三大指标（CD / NX / TT）含义与打法总结

> 基于 `CD.ftindex`、`NX.ftindex`、`TT.ftindex` 公式与三份《指标投资应用》PDF 的整理。
> 三大指标通过富途牛牛"自编指标"导入，手机 App 登录同账号即可同步。

---

## 一、三个指标的本质

### 1. TT — 机构吸筹信号（副图，绿/紫柱）
- 文件：`TT.ftindex`，标题 "TT 机构信号"。
- 公式核心：用 21 周期 EMA 把多个量级（90/250/500 周期）的 HHV/LLV 加权合成支撑线 `TTA`；再以 `LOW <= LLV(LOW,30)` 配合 SMA 成交动能合成 `TT_BUY`，画为副图柱。
- **绿柱（普通绿色）**：价格已跌入历史中长期支撑带，叠加机构吸筹动能 → 底部吸筹。
- **紫柱（高亮紫）**：在绿柱基础上同时满足三条加强条件，构成**强买入信号**：
  1. `GREEN_DECLINE` — 绿柱连续递减（动能耗尽，准备反弹）；
  2. `HORIZONTAL_RESONANCE` — 250 根回看内同位置曾出现同高度绿柱（"横向共振"）；
  3. `VOL_CONFIRM` — 成交量 > 20 日均量，或较前一根放量 1.5 倍。
- **顶部没有对称的卖出柱**。文档原话："机构卖出是上涨过程中分批抛货，所以上方粉色柱不会集中"——**TT 的卖点指引很弱**。

### 2. CD — 抄底/卖出信号（副图，文字标注）
- 文件：`CD.ftindex`，标题 "CD 抄底卖出"（旧版叫 CD001）。
- 公式核心：基于 MACD `D = EMA(C,12) - EMA(C,26)`、`A = EMA(D,9)`、`M = (D-A)*2`，识别相邻两个 MACD 周期的**底背离 / 顶背离**：
  - **抄底 (`DXDX`)**：价格创新低 + DIF 不创新低 + D<0、M<0（底背离），在副图打红字"抄底"。
  - **卖出 (`DBJGXC`)**：价格创新高 + DIF 不创新高 + D>0、M>0（顶背离），打绿字"卖出"。
- 区分两种形态：直接背离（`AAA`/`ZJDBL`）与高阶/跨周期背离（`BBB`/`GXDBL`），并对二次确认、连续背离做过滤。
- 一句话：**CD 是 MACD 多重背离捕捉器**，输出离散的"抄底 / 卖出"文字。

### 3. NX — 趋势梯子（主图，蓝/黄/紫通道）
- 文件：`NX.ftindex`，标题 "NX 趋势梯子"。
- 公式核心：双周期 EMA 通道
  - 短期 `TF1 = 26`：上沿 `EMA(H,26)`，下沿 `EMA(L,26)`；
  - 长期 `TF2 = 89`：上沿 `EMA(H,89)`，下沿 `EMA(L,89)`。
- 颜色含义：
  - 上下沿同时向上 → **蓝色**（多头）；
  - 上下沿同时向下 → **紫色**（空头）；
  - 否则 → 蓝色填充（震荡）。
- 当 K 线开/收盘穿越通道边缘时画粗柱（`STICKLINE`）作为突破事件标记。
- 一句话：**NX 是双周期 EMA 高低点通道，趋势/状态滤镜**，本身不给买卖点。

## 二、三种打法（PDF 总结）

| 打法 | 适用标的 | 核心逻辑 | 关键信号组合 |
|---|---|---|---|
| **一. 长线钓鱼** | 标普/纳指/七巨头/黄金/比特币等大宽基与大市值 | 4 小时或日线级别 **TT 绿柱 + CD 抄底** 在同一时间/价位**纵向共振**；TT 自身在前期同价位有相近绿柱构成**横向共振**；两者皆有则**纵横双共振**，可重仓 | TT 绿/紫柱 + CD "抄底" |
| **二. 集体行为（大盘择时）** | 多只代表性股票联动 | 多只重要股在 4H/日线**同时出现 CD 买入 → 大盘见底**；同时出现 CD 卖出 → 大盘见顶。把 CD 当作"群体情绪开关" | 多股 CD 信号集群 |
| **二-b. 1234 集体行为（个股择时）** | 单只目标个股 | **多周期共振**：1H/2H/3H/4H（最好叠日线）CD 同时抄底；前期 4H 卖出点为阶段高点且回撤 ≥ 25%；切 30 分钟看 K 线快速穿 NX 蓝色梯子上沿 → 入场 | CD 多周期共振 + NX 突破确认 |
| **三. 末日期权（仅 QQQ 当日 call）** | 仅 QQQ 当日到期 call | 1 分钟级 CD 出抄底 → 等 K 线快速站上 NX 蓝色梯子 → 买当日轻度虚值 call；NX 蓝线在黄线之上平行向上持有；蓝转紫立刻卖；1 分钟收盘跌破蓝色梯子下沿立刻止损；50% 强制止盈 | CD(1m) + NX(1m) 双确认 |

## 三、三个指标的角色分工（核心理解）

```
NX  →  趋势/状态滤镜    "现在是不是上行趋势？"   多空通道 + 突破
TT  →  仓位指引          "机构有没有在吸筹？"     大级别底部信号，弱卖出
CD  →  扣扳机            "该不该开仓/平仓？"       MACD 多重背离，离散文字提示
```

**联合使用范式**：
TT 选位置（大级别有没有吸筹） → CD 给信号（背离触发） → NX 看节奏（趋势/突破确认）。
**指标级别越大、共振越多，胜率越高**；级别越小（如 1 分钟末日期权），容错越低、风险越高。

## 四、文档反复强调的注意事项

1. 信号并非 100% 有效，必须自行回测、看历史走势验证。
2. 机构卖出**无集中信号**，卖点指引偏弱，需结合其他打法。
3. 末日期权严格控仓——**单日单单**、盈亏均强制止盈止损（50% 止盈、跌破 NX 蓝色梯子下沿止损）。
4. 初学者**只做 call，不做 put**；只做 QQQ。
5. 多观察、多复盘，把信号当作"机器规则"执行，不要凭感觉。
