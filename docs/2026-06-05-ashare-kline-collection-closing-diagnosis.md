# A股 K线采集与收线/聚合 根因诊断报告

> 日期:2026-06-05 · 状态:只读排查完成,待决策
> 触发:茅台(600519)近期 15m/30m 无数据、4h 落后 4 天。本报告只诊断,不含实现。

---

## 现象(实测 600519,2026-06-05 12:22 BJT,交易日)

| 周期 | 最新 bar(BJT) | 状态 |
|---|---|---|
| 5m | 06-05 11:30 | ✅ 最新 |
| 60m | 06-05 11:30 | ✅ 最新(从 5m 聚合) |
| 15m | 无 | ❌ 整个缺失 |
| 30m | 无 | ❌ 整个缺失 |
| 4h | 06-01 15:00 | ⏳ 落后 4 天 |
| 1d | 06-02 | ⏳ |

聚合口径本身正确:已用 06-01 / 6-03(补数后)的 60m 逐根对比富途茅台,时间网格(10:30/11:30/14:00/15:00)与 OHLC 均一致(仅 sina vs 富途前复权因子的末位小数差异)。**问题不在聚合算法,在采集覆盖与收线驱动。**

---

## 根因 1:A股 K线采集是「SSE 订阅驱动」,非热门周期不采

`apps/collector/ashare/bar_poller.py`(注释 1-6):
- 机制:`SSE 订阅 → Redis state:subscribe:ashare:{symbol}:{interval} → bar_poller 才轮询该 (symbol, interval)`;SSE 断开 → key 过期 → 轮询停止。
- 例外:`_DEFAULT_INTERVALS=(5m,15m,30m)` 仅对**大盘默认标的(指数)**始终轮询。
- 600519 不是大盘默认标的 → 它的 15m/30m **只在有人打开详情页订阅该周期时才采** → 平时无人订阅 → 库里空。
- 5m 有数据:它是信号/分时基础周期,被其他路径触发;60m 从 5m 聚合。15m/30m 两头不沾 → 空。

实测佐证:同一时刻 `ak_call.success ...600519...5m... shape(1970,7)` —— sina 对 5m 成功,**不是全局封 IP**,而是 15m/30m 没被触发轮询。

**结论**:这是"按需采集省 sina 调用"的设计副作用——CORE/自选标的的非热门周期(15m/30m)长期无数据,直到有人主动看。

## 根因 2:5m 收线→派生周期聚合触发不可靠(4h 落后)

- 4h 靠"5m 收线 → `aggregate_and_publish(targets=(60m,4h))`"触发(`bar_poller.py:149-155`)。
- 实测:60m 跟到 06-05,4h 停在 06-01 → **同一触发源,60m 更新了、4h 没有**。
- 推测:`aggregate_and_publish` 对 4h 桶的滚动/写入判定有遗漏(4h 桶跨度大,A股一天仅 2 根半棒,可能某些日期未触发写入),需进一步定位 `aggregate_derived` 对 4h 的处理。

## 回答用户的两个问题

1. **茅台近期为何没数据**:A股 K线采集订阅驱动,600519 的 15m/30m 无人订阅就不采(非 sina 全局封)。
2. **final=false→true 收线逻辑是否完善**:**不完善**——
   - 覆盖不全:未被订阅的 (symbol, interval) 根本不采集,无从收线。
   - 聚合不同步:5m 收线未可靠驱动所有派生周期(4h 落后 4 天)。

## 影响面

- 所有**非大盘默认标的**(CORE 个股 + 自选)的 15m/30m,平时无人看就空。
- 所有标的的 4h(及可能 60m 的部分日期)聚合可能滞后。
- 美股同构(bar_poller 订阅驱动)——需另测确认,但美股 CORE 标的实测各周期齐全(可能因详情页常被访问/CORE 覆盖不同)。

## 修法选项(待决策,均需改采集链路,先对齐再实现)

- **A. CORE∪自选 无条件采全信号周期**:bar_poller 对 CORE∪watchlist 标的始终轮询 5m/15m/30m(不依赖订阅),根治"非热门周期空"。代价:sina 调用量增加(需评估 B-sina 限频)。
- **B. 修聚合触发可靠性**:定位并修 `aggregate_and_publish` 对 4h 的滚动写入遗漏,保证 5m 收线同步驱动 60m/4h。
- **C. 按需回补**:维持订阅驱动,但首次打开标的时对其全信号周期发 refill(类似已做的加自选 refill),即时补齐。
- 推荐:**A + B**(根治覆盖 + 修聚合),C 作为即时兜底。
